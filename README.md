# Dream Factory

🍬 **Dream Factory（造梦工厂）** 的**公开占位仓库**。

## 本仓库是什么

- 一个公开可见的**项目门面**——告诉大家「Dream Factory / 造梦工厂」应用存在。
- **不存放任何源码**。应用（源自 miuix-example，包名 `com.dream.factory`）的开发源码放在私有仓库 [Dream-Factory-Private](https://github.com/Rune-cn/Dream-Factory-Private)（private，需授权访问）。

## 为什么这里不放源码

- 开发中、未就绪的代码先保持私有（详见 Dream-Factory-Private 的 [REPO_NOTE.md](https://github.com/Rune-cn/Dream-Factory-Private/blob/main/REPO_NOTE.md)）。
- 本公开仓库只承担**说明与门面**作用，不提供代码下载。

## 两边仓库的约定（互相解释）

| 仓库 | 可见性 | 内容 |
|---|---|---|
| Dream-Factory（本仓库） | public | 占位门面，**不放源码** |
| [Dream-Factory-Private](https://github.com/Rune-cn/Dream-Factory-Private) | private | **放源码**：Dream Factory（造梦工厂）应用开发副本，含内置 MCP 服务器 |

## 状态

- 目前没有可公开下载/部署的内容，本仓库保持「挂在这里」的占位状态。
- 完整的安排说明见 [REPO_NOTE.md](REPO_NOTE.md)。
